# Configuration du processus tarifaire

Le processus ne demande ni double validation, ni variable spéciale, ni
environnement GitHub supplémentaire.

La configuration nécessaire est limitée à ces points :

1. GitHub Pages utilise **GitHub Actions** comme source de publication.
2. Hamza et son responsable ont chacun un compte avec accès en écriture au
   dépôt.
3. Le workflow du dépôt est autorisé à écrire le contenu et à publier Pages.

Pour une mise à jour courante, remplacer uniquement
`Base_tarifaire_KRONO_plus.xlsx` dans ce dossier. Les contrôles et la publication
se lancent automatiquement.

Un voyant vert dans l'onglet **Actions** confirme le contrôle technique des
684 lignes et des 1 368 montants. Il ne constitue pas une preuve de provenance
commerciale pour les lignes encore signalées « à confirmer ».
